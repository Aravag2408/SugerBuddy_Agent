# API + GUI + Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the course-required FastAPI layer (4 endpoints), a minimal single-page GUI
(including the parent-decision-to-teen relay), and the Vercel deployment configuration, all wrapping
the already-built-and-tested `agent_pipeline.run_pipeline`.

**Architecture:** One FastAPI app (`api/index.py`) with all 4 endpoints plus the GUI's root route,
deployed as a single Vercel serverless function via a catch-all rewrite. The GUI is one
self-contained static HTML file with inline CSS/JS — no build step, no framework.

**Tech Stack:** FastAPI, Vercel's Python (ASGI) runtime, vanilla HTML/CSS/JS.

## Global Constraints

- `/api/team_info` must return exactly: `group_batch_order_number`, `team_name`,
  `students: [{name, email}]`. Team: **SugarBuddy** — Arava Gendelman
  (`aravag@campus.technion.ac.il`), Aya Grabarsky (`ayagrabarsky@campus.technion.ac.il`), Sofia
  Torgovezky (`sofiat@campus.technion.ac.il`). `group_batch_order_number` is
  `"TODO_FILL_BEFORE_SUBMISSION"` until the real value is known.
- `/api/agent_info` must return `description`, `purpose`, `prompt_template` (with `template`),
  `prompt_examples` (each with `prompt`, `full_response`, `steps`).
- `/api/model_architecture` must return `Content-Type: image/png`.
- `/api/execute` must return **exactly** `{"status", "error", "response", "steps"}` on every path —
  success, `PipelineError`, any other exception, and a missing/invalid `prompt` field all map to
  this same shape. Never let FastAPI's default validation-error shape leak through.
- Module names in any step object must be exactly `CGM Event`, `ReAct Agent`,
  `Confidence Classification`, `Parent Summary` — already enforced by `agent_pipeline.py`; this
  layer must not rename or duplicate them.
- No live LLM/Pinecone/Supabase network calls in automated tests — mock/monkeypatch at the
  `api.index` module boundary, consistent with the rest of this project.
- GUI must have no authentication guard of any kind and must be reachable at the root URL `/`.

def _step(module: str, user_prompt_payload, response: dict) -> dict:
    if isinstance(user_prompt_payload, str):

        user_prompt = json.dumps(user_prompt_payload, ensure_ascii=False, indent=2)

        "module": module,
        "prompt": {

            "user_prompt": user_prompt,
        },
        "response": response,
    }

```python
from fastapi import Request
from fastapi.responses import JSONResponse

from agent_pipeline import PipelineClients, run_pipeline
from errors import PipelineError
from llm_client import get_llm_client
from retrieval import get_pinecone_index_safe
from supabase_log import log_execution

_clients: PipelineClients | None = None


def _get_clients() -> PipelineClients:
    global _clients
    if _clients is None:
        llm_client = get_llm_client()
        pinecone_index = get_pinecone_index_safe()
        _clients = PipelineClients(llm_client=llm_client, pinecone_index=pinecone_index, embed_client=llm_client)
    return _clients


@app.post("/api/execute")
async def execute(request: Request):
    body = await request.json()
    prompt = body.get("prompt") if isinstance(body, dict) else None

    if not isinstance(prompt, str) or not prompt.strip():
        return JSONResponse({"status": "error", "error": "prompt is required", "response": None, "steps": []})

    try:
        clients = _get_clients()
        result = run_pipeline(prompt, clients)
    except PipelineError as e:
        return JSONResponse({"status": "error", "error": str(e), "response": None, "steps": []})
    except Exception as e:
        return JSONResponse({"status": "error", "error": f"unexpected error: {e}", "response": None, "steps": []})

    log_execution(prompt, result["response"], result["steps"])
    return JSONResponse(
        {"status": "ok", "error": None, "response": result["response"], "steps": result["steps"]}
    )

      "SYSTEM PROMPT:\n" + step.prompt.system_prompt +
      "\n\nUSER PROMPT:\n" + step.prompt.user_prompt +
      "\n\nRESPONSE:\n" + JSON.stringify(step.response, null, 2);
    details.appendChild(pre);
    return details;
  }

  function renderTurn(responseText, steps) {
    const turn = document.createElement("div");
    turn.className = "turn";
    const p = document.createElement("div");
    p.className = "response";
    p.textContent = responseText;
    turn.appendChild(p);
    steps.forEach((step) => turn.appendChild(renderStep(step)));
    log.appendChild(turn);
  }

  async function runAgent() {
    errorBox.style.display = "none";
    const userText = inputBox.value.trim();
    if (!userText) return;

    transcript = transcript ? transcript + "\n" + userText : userText;
    inputBox.value = "";
    runButton.disabled = true;

    try {
      const res = await fetch("/api/execute", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ prompt: transcript }),
      });
      const data = await res.json();

      if (data.status === "error") {
        errorBox.textContent = "Error: " + data.error;
        errorBox.style.display = "block";
        runButton.disabled = false;
        return;
      }

      renderTurn(data.response, data.steps);
      transcript = transcript + "\n" + data.response;

      if (data.response.includes("SUGARBUDDY_CONTEXT")) {
        runButton.textContent = "Send reply";
        inputBox.placeholder = "Your reply (answers or follow-up answer)";
      } else {
        runButton.style.display = "none";
        inputBox.style.display = "none";
        resetButton.style.display = "inline-block";
        parentSection.style.display = "block";
      }
    } catch (err) {
      errorBox.textContent = "Request failed: " + err;
      errorBox.style.display = "block";
    } finally {
      runButton.disabled = false;
    }
  }

  function resetConversation() {
    transcript = "";
    log.innerHTML = "";
    inputBox.value = "";
    inputBox.style.display = "inline-block";
    inputBox.placeholder = "Describe the CGM event (e.g. 'glucose spiked to 260 mg/dL and is rising fast')";
    runButton.textContent = "Run Agent";
    runButton.style.display = "inline-block";
    resetButton.style.display = "none";
    parentSection.style.display = "none";
    document.getElementById("parent-decision-input").value = "";
    document.getElementById("teen-message-box").textContent = "";
    errorBox.style.display = "none";
  }

  runButton.addEventListener("click", runAgent);
  resetButton.addEventListener("click", resetConversation);
  document.getElementById("send-to-teen-button").addEventListener("click", () => {
    const text = document.getElementById("parent-decision-input").value;
    document.getElementById("teen-message-box").textContent = text;
  });
</script>
</body>
</html>
```
